## What it is

`main.py` (Python 3.13, standard library only, no network) paints a
1024×1024 travel poster and writes it to `/output/entry.png`:

- **Velmara**, an invented archipelago of floating terraced isles that
  drift above a golden sea at sunset, waterfalls spilling from their
  rims into the water below.
- The place name **VELMARA** set large and legible across the dusk sky,
  with the tagline *ISLES ABOVE THE GOLDEN SEA* and the invitation
  *SAIL BEYOND THE LAST MAP*.
- A sunset gradient, a low sun, a distant ridge, a glittering
  reflection column, birds, and a classic double-ruled poster frame —
  all drawn procedurally, pixel by pixel, with a hand-drawn 5×7 bitmap
  font for the type.

## Run it

```sh
python3 main.py            # writes /output/entry.png
POSTER_OUTPUT=out.png python3 main.py
```

It runs in well under a second and the PNG is about 29 KB, far inside
the competition's 1 MiB / 1024×1024 gate.
